# Guardrail Maker

사용자가 네 이해나 행동을 교정하면 이를 감지해서 같은 교정이 두 번 일어나지 않게 지속적인 가드레일을 제안한다.

## 규칙

- 사용자 메시지를 하나하나 교정 신호가 있는지 살피고, 언어나 표현이 무엇이든 의도로 맞춘다. 등급은 "감지 계층" 표로 매긴다.
- 교정을 먼저 적용해서 현재 작업을 고치고, 그 뒤에 제안("제안 형식" 절)을 답변에 덧붙여 사용자 확인을 기다린 뒤에 쓴다.
- 앞으로의 실수를 막아주는 교정만 담고 나머지는 흘려보낸다. 판단은 "담을 만한가?" 표로 한다.
- 먼저 기존 규칙과 `CLAUDE.md`에서 겹치는 내용을 찾는다. 겹치면 두 번째 사본을 만들지 말고 기존 규칙을 고치자고 제안하며 diff를 보여준다. 새 내용이면 합의한 위치에 쓰되 대상 파일의 기존 문체를 따른다.
- 상주 규칙은 git이 추적하는 원본 트리(`rules/...`)에 쓰고, 설치된 symlink나 생성된 블록에는 쓰지 않는다. 먼저 실제 경로를 확인한다(`readlink -f ~/.claude/rules/ai-roots`). 상황별 skill은 `skills/<name>/SKILL.md`에 `name`과 trigger 중심 `description`을 담은 YAML frontmatter와 함께 넣는다. `install.sh`를 다시 돌리면 둘 다 전파된다.
- skill의 `description`은 요청에서 보이는 것에 맞아야 한다. 과제 종류, 산출물, 사용자가 한 말, 셀 수 있는 속성. 모델이 자기 상태를 알아채라고 요구하는 trigger("작업이 autopilot을 유혹할 때", "결과가 불확실할 때", "막연한 요청이 시간을 잡아먹은 뒤")는 발동하지 않는다. 그렇게 쓴 skill 네 개는 4번 중 0-1번 발동했고, 관찰 가능한 조건으로 다시 쓰자 4번 중 2-4번 발동했다. 이 수치는 발동만 측정한 것이다. 발동이 출력을 개선하는지는 측정할 수 없다. 대조군이 되려면 agent가 돌아가는 동안 그 skill이 닿지 않아야 하는데, skill 가시성은 세션 시작 시점에 고정된다.
- 명령형으로("X를 쓴다", "X를 써야 한다"가 아니라), 그 자체로 이해되게, WHY 한 문장을 붙여서, 구분이 미묘하면 구체적인 좋음/나쁨 짝과 함께 쓴다. 긍정 표현을 선호하되("Y를 쓰지 않는다"보다 "X를 쓴다"), 실수 자체가 핵심 신호라면 금지형도 괜찮다.
- 범위가 불분명하면 다른 프로젝트에도 적용되는 규칙인지 묻는다.
- 쓴 뒤에는 무엇을 어디에 썼는지 확인해준다.
- memory는 맥락을 추적하고, 가드레일은 행동을 강제한다.

## 감지 계층

| 계층 | 신호 | 확신도 |
|------|------|--------|
| 1 | 직접 교정. 이건 틀렸고 맞는 답은 이것이다. 정체와 의미 교정, 금지("하지 마", "그만", "절대"), 지시("항상", "이제부터"), 대체("Y 말고 X를 써") 포함. | 높음 |
| 2 | 반복 교정. "이미 말했잖아", "또 같은 실수", "몇 번을 말해야 해". 가치가 가장 높다. | 높음 |
| 3 | 관례 선언. 프로젝트나 팀, 도메인 규칙을 선행 실수 없이 미리 말해준다. 명명 규칙, 아키텍처 패턴, 워크플로 규칙, 도메인 용어 정의. | 중간 |
| 4 | 암시적 교정. "완전히 맞진 않아", "비슷한데 조금 달라", 조용한 재표현, 네 출력을 조용히 고치고 넘어가기. 가치를 더 신중하게 따진다. | 중간 |

## 담을 만한가?

| 담는다 | 넘긴다 |
|--------|--------|
| 앞으로의 작업에 적용되는 관례 | 일회성 사실 오류(잘못된 경로, 오타) |
| 반복되는 교정 패턴 | 설명으로 풀린 단순 오해 |
| 코드에서 유도할 수 없는 도메인 지식 | 기존 규칙이나 `CLAUDE.md`에 이미 있는 내용 |
| 행동 규칙(항상/절대) | 이 대화에만 해당하는 취향 |
| 프로젝트를 넘는 원칙 | 일시적 상태(branch 이름, 지금 PR) |

## 제안 형식

```
---
Guardrail proposal. Saving this as a rule prevents the same mistake in future conversations.

Rule: [one-line rule in imperative form]
Example: [concrete good/bad pair if applicable]
Location: [placement recommendation with rationale]
```

반복된 교정이면 한 줄로 충분하다.

```
---
Guardrail proposal: "[one-line rule]", save to [location]?
```
